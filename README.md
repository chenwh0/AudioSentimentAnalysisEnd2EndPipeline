# **Milestone 2 results**

Everything below was produced by an unattended run on 2026-11-18 (04:27 to 08:20 CST) on one local GPU, followed by a per-token attribution study the same day. The long version is [Milestone2/README.md](Milestone2/README.md) (theory, every figure with its reading, the per-token study); the audited report is [Milestone2/OVERNIGHT_REPORT.md](Milestone2/OVERNIGHT_REPORT.md); the run status and commit hashes are in [OVERNIGHT_STATUS.md](OVERNIGHT_STATUS.md); every decision with its clock time is in [logs/ledger.md](logs/ledger.md).

**How we got the results.** The data splits were never redone: all code reads the saved `development.csv` (500 clips), `test.csv` (1,500) and `load_pool.csv` (1,426) with their index files, tunes every threshold on the development slice, reports only on the test slice, and never reads the load pool, which is reserved for the T5 load generator. Human transcripts for all 3,426 clips come from the SLUE benchmark, so word error rate is measured against people, not against another model. Every number carries a 95% bootstrap confidence interval (10,000 resamples, seed 8001, paired when two models are compared), each table is regenerated by a script from cached transcripts, and fresh-context auditors re-ran the scripts and checked the report text against the files before the push.

**What the professor's four comments became.**
- Assertions are code in `Milestone2/T1_final/pipeline/assertions.py`: minimum word count, speaking rate, a confidence threshold tuned on the development slice, agreement between two classifiers, and an audio-quality check from the AADD degradation detector. The calibration result held: the confidence threshold carries no signal for the binary models, and classifier agreement is the check that works for all of them.
- ASR quality is measured directly. Against human transcripts the Whisper models make 18 to 22% word errors (AventIQ 0.183, whisper-tiny 0.221), Moonshine-base 0.161, and s2t-small 0.598 after fixing a batch-padding bug that had inflated it to 0.864. Running the sentiment models on the human transcripts raises Cardiff's macro-F1 by only 0.02 to 0.03 (to 0.637), while changing the classifier moves it by about 0.3. That is the answer to why the choice of speech model barely matters.
- SiEBERT's labels are mapped: a low-confidence prediction becomes neutral, with the threshold tuned on the development slice. The same is done for DistilBERT, and the 5-class tabularisai model is folded to 3 classes.
- The 127 disagreement and mixed clips are excluded and every result is macro-F1 over the three remaining classes, against an always-neutral baseline of 0.2826.

**Also in this run.** Six speech-to-text variants and four sentiment variants registered with pinned revisions, checksums and on-disk sizes (`Milestone2/T2_variants/`); a weight-space edit of whisper-tiny with no training that lowers word error rate by 0.005 but sentiment macro-F1 by 0.006, both significant (`Milestone2/WSP_Whisper/`); and the AudioXAI tool, which tested and refuted the hypothesis that the speech models attend to degraded audio (`Milestone2/AudioXAI/`). The per-token study in `figures/xai_tokens/` shows, for 20 test clips and three models, which 100 ms of audio each output token used, with audio quality drawn alongside.

## Step 1: Audio to Text

To convert the given audio files you will need to learn about speech to text conversion.
A tutorial on the same can be found here: 
https://www.geeksforgeeks.org/deep-learning/pytorch-for-speech-recognition/?utm_source=chatgpt.com

A more detailed documentation of Speech to Text models on HuggingFace can be found here:
https://huggingface.co/docs/transformers/model_doc/speech_to_text?utm_source=chatgpt.com

Here are two models that can be found on huggingface that can do audio to text conversion:

1. AventIQ-AI/whisper-audio-to-text
2. facebook/s2t-small-librispeech-asr

## Step 2: Text Sentiment Analysis

To perform sentiment analysis on the text generated by the previous step, you are tasked
