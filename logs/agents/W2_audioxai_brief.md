## Build (package R/Milestone2/AudioXAI/)
- HYPOTHESES.md FIRST (within 10 minutes): H1 (ASR attribution concentrates in AADD-flagged regions more than their share of duration; refuted if the focus ratio's 95% CI includes 1 or lies below it), H2 (ASR errors concentrate in flagged segments and fall on low-sentiment-importance words; refuted if error rate inside flagged ≤ outside or if the sentiment-importance share of erroneous words ≥ their word share), H3 (the text classifier is the bottleneck; decided by Phase 1's gold-text ablation: holds if gold text does not raise Cardiff macro-F1 beyond the paired CI). State the exact statistics and refutation criteria.
- audioxai/ package with pyproject.toml; CLI `audioxai explain --clip <id> --asr <model> --sentiment <model>`, `audioxai scan --slice test --sample 50 --out results/`, `audioxai report --out report.html`.
- Per clip (whisper-tiny): (1) waveform and the exact log-mel from WhisperFeatureExtractor (80 bins, 10 ms hop), cropped to the clip duration for every metric (mask padding frames). (2) AADD timeline from the files above. (3) tokens with timestamps: model.generate(..., return_token_timestamps=True) with alignment heads (generation_config.alignment_heads is set on this checkpoint). (4) M1: gradient × input on the log-mel with SmoothGrad n=8, σ = 0.1 × feature std, using the teacher-forced log-probability of each generated token given the model's own previous tokens (batch the 8 noise samples; one backward per token). M4: decoder cross-attention averaged over the alignment heads (time-only; label it so). M3 (Grad-CAM on the last encoder layer via captum LayerGradCam, time-only) only if time remains. M2 (spectrogram occlusion) only if time remains after the test run. (5) word-level errors vs gold from jiwer.process_words alignment, placed on the timeline through token timestamps (words = merged tokens). (6) sentiment word importance: captum LayerIntegratedGradients on Cardiff's embedding layer for the predicted class, projected to audio time through word timestamps. (7) end-to-end segment replacement (500 ms windows, 250 ms stride, noise floor) only if time remains.
- Aggregates (results/aggregate.csv, one row per clip): focus ratio (attribution mass inside flagged 20 ms frames ÷ fraction of frames flagged; report the number of clips with zero flagged frames and keep them in the table with NaN, do not drop them silently), WER inside flagged vs clean segments, sentiment-importance share inside flagged, Cardiff correctness. Bootstrap 95% CIs (10,000 resamples, default_rng(8001)) for the mean focus ratio and for a point-biserial correlation of each metric with sentiment correctness; also per degradation class. results/summary.json with the H1–H3 verdicts and CIs.
- Faithfulness: deletion curves (remove top-k% salient patches, k in 5..50, vs random patches of the same size; drop in teacher-forced log-prob; AUC of each) on ≥ 20 clips; model-randomization sanity check (re-initialize the top 2 decoder layers on a copy, recompute M1; report Spearman correlation between original and randomized maps; PASS only if < 0.5) on ≥ 10 clips. Report failures as findings.
